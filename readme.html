The complete guide to managing your BrickLink inventory storage.

🚀 Core Tools

🔍 Gap Auditor

Finds empty holes in your drawers. It scans your REMARKS field and compares it to your physical layout to show exactly what is empty.

🛡️ Condition Guard

Safety first! This tool checks every container to ensure you haven't mixed New and Used parts in the same drawer or box.

📁 Profile Commander

Allows you to create different "Layouts" for your store. You can have a profile for your Main Wall and a different one for your Back Stock.

📖 "Idiot-Proof" How-To Guide

Step 1: Setting up your Warehouse

In the sidebar, look at the Layout Editor. Each "Category" (Drawers, Boxes, etc.) needs four numbers:

  • Prefix: What you type in BrickLink (e.g., B for Boxes). Leave blank for standard drawers.
  • Start/End: The range of the units (e.g., Box 1 to Box 40).
  • Holes: How many slots are in that unit (Drawers = 1, Boxes = 30).

Step 2: Using the Search Filters

This is the most powerful part of v4.1.0. Use the filters at the top of the sidebar:

  • Max Qty / Slot: Set to 0 to find totally empty holes. Set to 5 to find "nearly empty" holes you can top up.
  • Condition Focus: Tell the app you only want to see holes that are already Used so you don't accidentally put a New part in them.

Step 3: Understanding the Visual Grid

When you expand a Box or Case, you will see a color-coded map:

Green: Matches your search (Totally Empty)
Yellow: Matches your search (Low Qty / Nearly Empty)
Faded Red: Occupied or doesn't match your filter

📂 Profile Management

To save your work so you don't have to type it again:

  1. Type a name in the Save As New Name box.
  2. Click 💾 SAVE PROFILE.
  3. Next time, just select it from the Load Profile dropdown.

👻 Troubleshooting: "The Ghost in the Machine"

If you update your code but the app doesn't change, or you get a "Dubious Ownership" error, run this command in your terminal:

git config --global --add safe.directory "*"

This "Unlocks" your network drive so the application can see your latest changes.
